# Projeto de Consumo de APIs

Projeto desenvolvido para praticar JavaScript, manipulação do DOM e consumo de APIs.

Funcionalidades

Pedidos: validação, filtros e cálculo do faturamento.
Buscador de CEP: consulta de endereços pela ViaCEP e histórico de pesquisas.
Mini Pokédex: busca de Pokémon, imagem e tipos pela PokéAPI.
Tratamento de estados: carregamento, erro, não encontrado e sucesso.


Tecnologias

HTML5, JavaScript, Fetch API, Promises e async/await.



Reflexão: Promise.all

O `Promise.all()` permite iniciar várias requisições em paralelo, economizando tempo em comparação com vários `await` sequenciais.
